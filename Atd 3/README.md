# ClimaTempo — atividade guiada

1. Abra `Tutorial_ClimaTempo_Passo_a_Passo.docx` e execute as etapas na ordem.
2. Use `climaTempo.html` e `style.css` sem modificações obrigatórias.
3. O `script.js` incluído contém uma implementação completa de referência. Para fazer a atividade do zero, comece com um arquivo vazio ou com `script_inicial.js`, se estiver disponível.
4. Use o `script.js` para conferir as consultas, o preenchimento do DOM e o tratamento de erros. O professor pode removê-lo antes de distribuir o pacote aos alunos.
5. Abra pelo Live Server e acompanhe o Console (F12).

APIs: https://open-meteo.com/en/docs e https://open-meteo.com/en/docs/geocoding-api
