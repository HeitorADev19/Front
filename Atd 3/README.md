# ClimaTempo — atividade guiada

1. Abra `Tutorial_ClimaTempo_Passo_a_Passo.docx` e execute as etapas na ordem.
2. Use `climaTempo.html` e `style.css` sem modificações obrigatórias.
3. Comece seu próprio `script.js` vazio, ou copie o conteúdo de `script_inicial.js`.
4. O arquivo `script.js` incluído é uma **referência de conferência** das consultas (não resolve o desafio do DOM). O professor pode retirá-lo antes de distribuir o pacote aos alunos.
5. Abra pelo Live Server e acompanhe o Console (F12).

APIs: https://open-meteo.com/en/docs e https://open-meteo.com/en/docs/geocoding-api
